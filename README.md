# Transport AI

An AI-powered transport disruption information and passenger assistance prototype built for **IntelliCon26**.

## Overview

Transport AI helps passengers receive clear, timely information during transport disruptions such as delays, cancellations, route changes, traffic incidents, or service interruptions.

The prototype provides an API foundation that can later support features such as:

- Real-time disruption alerts
- AI-generated passenger assistance messages
- Route and alternative transport suggestions
- Delay and cancellation reporting
- Multilingual passenger communication
- Transport authority or operator dashboards

## Tech Stack

- Python
- FastAPI
- Uvicorn
